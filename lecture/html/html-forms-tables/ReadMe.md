# HTML Semantics, Forms, and Tables

A beginner-friendly project for learning three important parts of HTML:

- Semantic HTML
- HTML Forms
- HTML Tables

## 📚 Topics

### 1. Semantic HTML

Semantic HTML uses elements that clearly describe their purpose.

Common semantic elements:

| Element | Purpose |
|---|---|
| `<header>` | Page or section header |
| `<nav>` | Navigation links |
| `<main>` | Main content |
| `<section>` | Groups related content |
| `<article>` | Independent content |
| `<aside>` | Related or secondary content |
| `<footer>` | Footer information |

Example:

```html
<header>
  <h1>My Website</h1>
</header>

<nav>
  <a href="/">Home</a>
  <a href="/about">About</a>
</nav>

<main>
  <section>
    <h2>About Me</h2>
    <p>This is my website.</p>
  </section>
</main>

<footer>
  <p>Copyright 2026</p>
</footer>
