# 🍔 Burger House — Responsive Website

Welcome to **Burger House**, a responsive restaurant website created as a web development project.

## 🔗 Live Website

👉 **[Click here to view the Burger House website](https://htmlpreview.github.io/?https://github.com/alfrenJames/FWS-2026-9-3/blob/main/lecture/burger-responsive-design/index.html#home)**

## 📌 Project Information

- **Project Name:** Burger House
- **Project Type:** Responsive Restaurant Website
- **Technologies Used:** HTML, CSS, JavaScript
- **Repository:** [FWS-2026-9-3](https://github.com/alfrenJames/FWS-2026-9-3)

## ✨ Features

- Responsive layout for desktop, tablet, and mobile devices
- Navigation menu with a mobile-friendly hamburger menu
- Restaurant food and menu sections
- CSS transitions and hover effects
- Flexible layouts using Flexbox and CSS Grid
- Responsive styling using CSS media queries

## 🎯 Learning Objectives

This project demonstrates the practical application of:

- HTML page structure and semantic elements
- CSS layout techniques and the box model
- Flexbox and Grid
- Responsive web design and media queries
- Navigation and interactive UI elements
- CSS transitions, transforms, and hover effects

## 📱 Responsive Design

The website is designed to adapt to different screen sizes:

- **Desktop:** Full navigation and spacious content layout
- **Tablet:** Adjusted spacing and content arrangement
- **Mobile:** Compact layout with a hamburger navigation menu
